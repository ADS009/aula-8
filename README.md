
# ADS-09 – Projeto Responsivo com Figma e Bootstrap

Este projeto foi desenvolvido como parte do curso de Análise e Desenvolvimento de Sistemas (ADS), no módulo 09. Foi um marco importante no meu aprendizado, especialmente por envolver práticas modernas de design e desenvolvimento web, com foco total na responsividade.

## ✨ Objetivo

Criar uma interface web que se adapte perfeitamente a diferentes dispositivos, com base em um protótipo desenvolvido no Figma e implementado com HTML, CSS e Bootstrap.

## 🛠️ Tecnologias Utilizadas

- **Figma** – para desenvolvimento do protótipo de interface https://www.figma.com/proto/kdFqVgcHILhjV7jyqq75Dn/Projeto-de-Interface-009---Naneto?node-id=111-10&t=2E2FwkzeUtTtJRPq-1//               
- **HTML5** – estrutura do conteúdo
- **CSS3** – estilização customizada
- **Bootstrap** – responsividade e componentes prontos

## 📐 Design com Orientação Profissional

O projeto contou com **monitoria de um especialista em Figma**, com foco em **Design UX (User Experience)** e **Design UI (User Interface)**. Isso garantiu maior cuidado com a experiência do usuário e a estética visual da aplicação.

## 📱 Design Responsivo

Este projeto foi desenvolvido com **design responsivo** como requisito principal. A interface se ajusta de forma fluida para oferecer uma experiência consistente em **celulares, tablets e desktops**.

A responsividade foi alcançada com a utilização da **grid do Bootstrap**, media queries e boas práticas de design.

## ⚙️ Funcionalidades Implementadas

- Layout adaptável para múltiplas resoluções de tela  
- Integração com protótipos criados no Figma  
- Estilo limpo e moderno com componentes do Bootstrap
